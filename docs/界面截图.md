# CenWallet 全部界面截图

截图来自 iPhone 16e / iOS 26.0 模拟器中的应用窗口，分辨率 1170 × 2532。共 **64 张**，包括 48 个路由页面和 16 张补充状态截图。所有 PNG 均保留原始分辨率。

点击图片可查看原图；长页面另附滚动后的截图。重新生成：`./tools/capture_screenshots.sh DEVICE_ID`。
